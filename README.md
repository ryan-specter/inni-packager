# inni-packager

Mirrors releases of Innioasis and Timmkoo firmwares and provides pre-packaged zips with portable flashing application binaries for various OSes and architectures. 

Windows: Innioasis Updater and SP Flash Tool
Linux: Innioasis Updater, MTKclient and SP Flash Tool
macOS: Innioasis Updater

## Windows XP/7/8 packages

Windows releases also publish `<rom>-windows-legacy.zip`. It is the same
firmware packed beside the flash tool alone, without Updater CE, because the
app needs 64-bit Windows 10 or later. It is built from the updater
repository's `SP_Flash_Tool-Windows.zip` asset and carries `donate.txt` plus a
`README.txt` quick start. The site serves it only to computers whose browser
reports Windows XP/Vista/7/8/8.1 or 32-bit Windows.
